SunDesk Web - local PC package
================================

How to start (one click, no command to type):

  Windows : double-click  start-windows.bat
  macOS   : double-click  start-mac.command
            (first time on macOS: right-click -> Open, then confirm)

Your browser opens http://localhost:8080 with the SunDesk connection
page. Enter IP/server, key and SN there as usual.

Requirements:
  - Python installed ("python" on Windows, "python3" on macOS)
  - Close the small server window when finished.

Manual alternative:
  cd into this folder and run:  python -m http.server 8080
  then open http://localhost:8080
